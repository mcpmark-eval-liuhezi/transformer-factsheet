# transformer-factsheet

Fact sheet for the reading-group presentation of **"Attention Is All You Need"**
(Vaswani et al., arXiv:1706.03762).

Every claim was checked against the paper's own text before presenting, so the
group can see exactly where each number comes from. See [`fact-sheet.md`](fact-sheet.md)
for the verdicts — each block quotes the wording or figure found in the paper
(abstract, model architecture, training setup, and results) and where it appears.

Verified against **arXiv 1706.03762 v7** (last revised 2 Aug 2023 — the current
version on arXiv at the time of checking).
